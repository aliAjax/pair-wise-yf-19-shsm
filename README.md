# hxyfront-62007 植物标本馆入库

以**采集事件**为核心的压制标本入库前端：同一场采集（同地点 / 海拔 / 生境 / 采集人）归为一个事件，标本不再逐份重复登记地点信息。

## 核心流程

1. **登记标本**：先选择已有采集事件（或就地新建，事件号自动生成），再录采集号与物种名称；地点、海拔、生境、采集人由事件继承。
2. **事件更正**：修改事件的地点或海拔后——
   - 未上柜标本自动跟随事件新值，无需逐份返工；
   - 已上柜标本保留上柜时的原值快照，并标记**待复核**，在详情页选择「采用事件新值」或「保留原值」。
3. **入库队列**：可按鉴定状态（待鉴定 / 已鉴定）和上柜状态（未上柜 / 已上柜 / 待复核）筛选，支持按采集号 / 物种 / 事件号 / 地点搜索。
4. **标本详情**：展示所属事件信息卡、同事件标本列表、修改记录时间线和柜位；上柜时柜位唯一，冲突会指出原先占用的采集号。
5. **数据持久化**：全部数据存于本机浏览器 localStorage，重开页面可继续处理；页头可导出 JSON 备份或重置演示数据。
